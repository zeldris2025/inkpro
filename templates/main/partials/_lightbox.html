{% comment %} Shared image lightbox overlay. The including element supplies the Alpine state: x-data="{ open: false, current: null }" and each trigger sets `current` to { src, caption, category } before flipping `open`. Kept as one partial because three pages (services, service detail and the gallery) need identical behaviour. Closes on Escape, on backdrop click, and on the close button. Page scrolling is locked while it is open so the background does not drift behind the image. {% endcomment %}
